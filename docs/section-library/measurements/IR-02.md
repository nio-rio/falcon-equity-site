# IR-02 live measurements (three headline stats)

- **Captured:** 2026-10-22
- **Source:** https://ir.blackstone.com/bx-share-information/default.aspx — `.module-stock-header`
- **Used by:** MCA hero stat grid. Live IR is **value then label**; MCA **flips** to label above value. Hairline stays **above** the cell (not under, unlike IR-03).
- **Method:** Playwright + `getComputedStyle` / `getBoundingClientRect` at 1440 / 1024 / 390 (`deviceScaleFactor: 1`).

## How to reuse

- Same Q4 frame as IR-01: **1200 / 994 / 360**.
- **3 equal columns** (`.grid_col--1-of-3`). MCA adds a second row of 3 (term facts + three Requirements).
- Each cell has a **2px solid black top rule**. Rule-to-text is **`padding-top: 40px`**.
- Rule length is **capped at 320px** (full inner column when the column is narrower, as at 1024 = 318px). At 1440 the column is ~400px and the rule stays 320px, left-aligned — visual gap between rules ~82px.
- Value: **38px / 38px / 300** Sanomat. Label: **20px / 22px / 300** Guardian Sans.
- Value `margin-bottom: 25px` (the gap between the big figure and the label under it). After the MCA flip, that 25px sits between label and value.
- Module padding **0**. Header module height 137 (desktop).
- Live IR-02 is one row, so it has no row-gap. MCA’s second row reuses the **90px** heading-to-rule air so each row of rules has the same space above it.
- White / transparent background. Skip the live price change, “View share details”, and footnotes.

- **Value:** 38px / 38px / 300

## 1024 CSS px

- **Module:** 994×137 at x 15
- **Columns:** 338px; inner/rule **318px** (under the 320 cap)

## 390 CSS px

- Live IR hides columns 2–3 and stacks the price ticker: full-width **360px** top rule, label first (10px pad), then 38px value.
- MCA keeps all six stats and stacks them 1-col, full-width rules, **40px** row-gap so the hero does not run on.
